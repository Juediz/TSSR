# Exercice

* OSI: open systeme interconnexion. C'est les 7 couches qui encapsule toutes les possibilités d'un pc à internet. physique, liaison de données,réseau.
* TCP/IP: deuxieme options pour l'osi ,4 couches.
* Bios/Uefi: c'est une option qui permet de configurer le lancement et la puissance de la machine. La différence entre les deux est que l'uefi a un interface graphique, il est plus rapide.
* ISO/images: c'est un format compressé d'un OS
* WDS/deploiement:(Windows deploiement services) c'est dans windows serveur une option qui déploiement un système d'exploitation avec un fichier boot.wim et windows.wim.**CHERCHER LE LIEU OU INSTALLER CES FICHIERS**
* Bridged/Nat/Hostonly: Ce sont des paramètres de la carte réseau sur vmware.
* octet/bits : 1 octet = 8 bits. Ils permettent de définir une adresse IP, d'effectuer des calculs binaire.
* PXE:(preboot eXecution environnement) c'est le démarrage du pc qui part sur pxe c'est un lancement automatique sans os
* Dhcp:(dynamique host configuration protocol) il permet d'adresser une ip automatique à n'importe qu'elle pc dans un réseau
* MBR/GPT: rufus. Table de partitionnement du bios => mbr. (master boot record)(gueid partition table) => partitionnement du uefi.
* Rufus/Ventoy: Installation de OS avec une clef usb bootable. Ventoy peut en enregistrer plusieurs.
* Partition:  couper un disque dur en plusieurs parties.
* Ntfs: (new technologie find system) systeme de fichier qu'on retrouver sur windows.
* SHA256(signature):CIA (confidiensalité intégrité authenticité) Pour etre sur que personne n'ai pirater un logiciel qu'on veut installer.
* Vmware: permet de faire des tests avec des ISOs en virtualisation.
* Windows serveur: OS qui permet de gérer un parc informatique
* Hyperviseur t1/t2: Type un il est sur le net via exsi par exemple pour gérer des serveurs. Type 2 c'est un hyperviseur qui est lié a une machine.
* DNS: domaine name services, il résoud un nom à une ip.
* @IP/MAC: l'ip c'est l'identité d'une adresse réseau.Le mac est l'adresse physique du pc où il à été fabriqué en hexadécimale en 6.
* Ieee 802.3/11: norme cable.
