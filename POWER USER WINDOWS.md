# Cours POWER USER WINDOWS

## Notions retenues sur l'évolution de Windows

- **1968** : création d'Intel.
- **1970** : UNIX, système d'exploitation.
- **BSD** : dérivé ("child") d'UNIX.
- À approfondir : **Windows 1**, qui tournait au-dessus de MS-DOS.
- **@** : symbole associé au départ d'Internet.
- **2007** : Android.

## Sites ou logiciels utiles pour la formation

- [Eylenburg](https://eylenburg.github.io/)
- **Microsoft Learn** : site à retenir.
- **PowerToys Run** : lanceur d'applications et de commandes rapide.

## Raccourcis Windows au clavier

| Raccourci | Action |
|---|---|
| `Win + L` | Fermer la session / verrouiller le PC |
| `Win + R` | Ouvrir la boîte "Exécuter" |
| `Win + E` | Ouvrir l'Explorateur de fichiers |
| `Ctrl + W` | Fermer l'onglet ou la fenêtre active |
| `Win + X` | Ouvrir le menu des paramètres / outils avancés |
| `Win + P` | Étendre ou dupliquer l'écran |
| `Win + D` | Réduire toutes les fenêtres / afficher le Bureau |
| `Win + M` | Réduire toutes les fenêtres |

## Commandes de la boîte "Exécuter"

| Commande | Utilité |
|---|---|
| `regedit` | Éditeur du Registre |
| `control` | Panneau de configuration |
| `devmgmt.msc` | Gestionnaire des périphériques |
| `ncpa.cpl` | Cartes réseau / connexions réseau |
| `gpedit.msc` | Éditeur de stratégie de groupe |
| `mstsc` | Contrôle à distance / Bureau à distance |
| `secpol.msc` | Stratégie de sécurité locale |
| `diskmgmt.msc` | Gestionnaire des disques |
| `compmgmt.msc` | Gestion de l'ordinateur |
| `eventvwr.msc` | Observateur d'événements |
| `services.msc` | Services Windows |
| `msinfo32` | Informations système |
